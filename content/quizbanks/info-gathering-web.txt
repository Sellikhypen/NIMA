? Was ist der Unterschied zwischen Subdomain und Virtual Host (vHost)?
+ Subdomains stehen im DNS, vHosts werden über den Host-Header auf demselben Server unterschieden
- Es gibt keinen Unterschied
- vHosts brauchen immer eine eigene IP
- Subdomains funktionieren nur mit HTTPS

? Welche Website durchsucht Certificate-Transparency-Logs nach Subdomains?
= crt.sh

? Warum sind Certificate-Transparency-Logs für Recon interessant?
+ Jedes ausgestellte TLS-Zertifikat wird öffentlich protokolliert – inkl. Subdomains
- Sie enthalten private Schlüssel
- Sie verraten Passwörter
- Sie listen offene Ports
