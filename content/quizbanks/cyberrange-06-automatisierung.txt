? Über welchen Port und welches Protokoll konfiguriert Ansible Windows-Systeme verschlüsselt?
+ WinRM über Port 5986
- SSH über Port 22
- RDP über Port 3389
- SMB über Port 445

? Was bedeutet Idempotenz bei Ansible?
+ Ein zweiter Lauf ändert nichts mehr, wenn der Soll-Zustand schon erreicht ist
- Jeder Lauf installiert alles neu
- Ansible arbeitet nur einmal
- Tasks laufen parallel auf allen Hosts

? Wann läuft ein Ansible-Handler?
+ Nur wenn ein anderer Task eine Änderung gemeldet hat
- Bei jedem Lauf immer zuerst
- Nur bei Fehlern
- Nie automatisch

?tf Ansible braucht auf jedem Zielsystem einen dauerhaft installierten Agenten.
= falsch
! Ansible ist agentenlos: SSH bzw. WinRM, Modul übertragen, ausführen, löschen.

? In welcher Reihenfolge hängen die OpenTofu-Module der Range voneinander ab?
+ network → firewall → vm → inventory
- vm → network → inventory → firewall
- inventory → vm → firewall → network
- alle gleichzeitig ohne Abhängigkeit

? Was ist Drift?
+ Eine Abweichung zwischen Code (Soll) und tatsächlicher Infrastruktur (Ist)
- Ein langsamer Festplattenzugriff
- Eine Zeitabweichung der Uhr
- Ein Fehler in der Firewall

? Mit welchen Befehlen erkennt man Drift? (mehrere)
+ tofu plan
+ ansible-playbook --check --diff
- tofu destroy
- rm -rf

? Welches Werkzeug prüft nach dem Ansible-Lauf in YAML, ob Ports offen und Dienste aktiv sind?
= Goss

? Was passiert bei einer Notfalländerung während der Übung?
+ Sofort umsetzen, dokumentieren und noch am selben Tag als Pull Request nachziehen
- Gar nicht dokumentieren
- Erst nach einem Monat in Git übernehmen
- Die Übung neu starten
